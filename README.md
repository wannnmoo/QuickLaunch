# QuickLaunch

Windows 桌面快捷启动面板 —— 毛玻璃 Dock 栏悬浮桌面，一键启动程序、文件夹和系统位置。

## 功能

- **快捷方式解析**：支持 `.lnk` / `.url` / `.pif`，高清图标提取（256×256）
- **拖入即添加**：从资源管理器把快捷方式或 exe 直接拖到 Dock 栏即可加入（按落点插入，重复或格式不支持会提示跳过）
- **文件夹收纳**：添加文件夹到 Dock，系统原生黄色文件夹图标
- **文件夹悬停预览**：鼠标悬停文件夹图标即弹出预览卡片——目录优先排列的子项列表（真图标 + 文件大小）、文件夹/文件数量摘要与「打开」按钮；图标分批补齐，读取全程不调用 PowerShell
- **系统位置**：自动加入「此电脑」「回收站」，图标从注册表动态解析
- **桌面文件夹同步**：桌面上的文件夹实时跟随——新增自动入 Dock，删除自动移除图标，无需手动维护
- **分组堆叠（Stack）**：把图标拖到分组图标上归入一组，分组图标显示组内前 4 个图标的缩略拼图与数量徽标；点开是**与主 Dock 同构的迷你面板**（同样的图标尺寸、悬停放大与标签行为，宽度随内容伸缩）
- **分隔线**：图标右键「在此之前插入分隔线」，把 Dock 分成逻辑区段；可拖动调整位置，样式随主题
- **键盘导航**：`Alt+Space` 唤出即选中（记住上次位置），`←/→` 移动、`Enter` 启动、`Esc` 退出；分组上 `→` 进入面板、`←` 返回；方向键随时可「唤醒」选中框
- **拖拽排序**：按住图标拖动到任意位置，蓝色指示线实时显示插入点
- **Dock 放大效果**：鼠标靠近图标时平滑放大 + 上浮；名称标签悬停显示（macOS 式悬浮在图标上方）
- **右键菜单**：编辑（名称 / 启动参数 / 工作目录 / 更换图标）、打开文件位置、以管理员身份运行、复制路径、新建分组、插入分隔线、删除
- **持久化存储**：所有图标自动保存，重启不丢失
- **透明窗口**：毛玻璃 Dock 悬浮桌面；**停靠位置三档**（「+」菜单分段选择器：中间 / 下 / 上），切换是原地换坐标（不重建窗口、不重载页面、无白闪）。窗口不支持自由拖动——位置只由预设决定，避免移动时的布局跳动
- **多主题**：「+」菜单**分段选择器**切换——透明 / 毛玻璃（黑夜 · 白天）；透明风格背景全透明，图标直接悬浮桌面
- **桌面图标开关**：一键隐藏 / 显示桌面图标
- **开机自启动**：「+」菜单开关（注册表 Run 登录项），开机静默隐藏到托盘
- **启动后自动隐藏**：点击图标启动后 Dock 自动隐藏到托盘，托盘/`Alt+Space` 随时唤回
- **系统托盘**：关闭窗口最小化到托盘，`Alt+Space` 切换显隐

## 开发

```bash
npm install
npm run dev        # 开发模式（HMR + 热重载）
npm run typecheck  # 类型检查
npm run build      # 生产构建
npm run package    # 打包为 Windows 安装包
```

## 项目结构

```
resources/           # 图标资源
  icon.ico           # 应用图标（多尺寸）
  tray-icon.png      # 托盘图标（16×16）
src/
  main/              # Electron 主进程（IPC、窗口、托盘、PowerShell）
  preload/           # contextBridge API + 类型定义
  renderer/          # React 前端（Dock UI、拖拽排序、放大效果）
```

## 平台

仅限 Windows —— 依赖 PowerShell / Win32 API / WScript.Shell COM。
